# 🧭 Molfar Vertep 1.17.0

**Order:** get this engine release and restart, then update Roleplay to 4.136.2 (Settings > Updates).

## Updates dialog (#318)
- **An app with no update source gets a row.** An app made on this device or copied in by hand used to be missing from Updates with no explanation. It now has a quiet row ("No update source") with the reason.
- **The engine row's warning says the right thing.** It claimed an app "needs a different version of Molfar Vertep" and "may stop working after the update". The range an app writes in `engine` is checked against the app contract, not the release, and the apps it named already failed today. The row now says "app contract", shows the contract this engine supports, and lists only your own apps (it used to count every account's).
- **A bad `engine` range is refused at install.** A Git or Store install and a zip import stop with a message that names the contract the app asks for and the one this engine has. Before, a release number such as `>=1.12.0` written there showed up only at the app's first update.

## Build failures (#337, the wording half)
When no build of an app has ever finished, the build-failed card and the app's own window say the first build failed and there is nothing to show yet, instead of "the app shows its last good build". A ready-made build for phones is still open.

## Roleplay 4.136.2 (an app update)
- **A lorebook file in the app's own format keeps its names, folders, constant status, depth, order and settings (#295).** A file without a `vectorized` key used to import as "Entry 1", "Entry 2" with no folders, and a constant entry never fired.
- **A message you stopped no longer comes back into the box (#384).** Stop, then a quick second send could return the first message to the box although it was stored, and sending it again would double it.
- The gallery's "Attach to message" obeys the 8-attachment cap.

## Not tried yet

## How to get it
From source: `git pull && bun install && (cd client-agent && bun install) && bun run build:client`, then restart. Downloads and the Android APK are on this release page. See [CHANGELOG.md](https://github.com/MolfarWav/Molfar.Vertep/blob/main/CHANGELOG.md).
