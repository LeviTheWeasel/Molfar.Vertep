# 🔌 Molfar Vertep 1.16.10

**Order:** get this engine release and restart, then update Roleplay to 4.136.1 (Settings > Updates).

## Which embeddings model a device uses is no longer synced (#431)
A computer with its own embeddings model (the one downloaded in Settings > Memory, LM Studio, Ollama) and a phone that has only an online connection share one profile through Sync. The choice of source used to travel with the profile, so the computer's "use my local model" reached the phone, which has no such model, and matching by meaning stopped working there after every sync.

- The choice (the model, the source, the model connected on this computer) now lives in a file of its own on each device. Neither a sync nor a backup carries it. A new device starts on Automatic.
- On update, a device takes over what the old settings held (a local model that is not downloaded on this device is dropped and "local" goes back to Automatic) and removes it from the synced settings. A phone that already pulled the computer's old choice starts on Automatic and keeps whatever you set there afterwards.
- Not changed: the connections themselves still sync. If you chose a connection to a model on your computer by hand, the phone still lists it; Automatic skips a server that does not answer, a hand-picked one does not fall back.

## Roleplay 4.136.1 (an app update)
- **Regenerate shows Stop at once (#382).** The new reply waits for the World DM to take back what it wrote from the old one, and Stop used to appear only when the request started. A Stop in that wait now cancels the run before anything is sent; the old reply stays.
- **A streamed reply no longer loses its first words (#383).** The page replaced its live socket on every refresh of the data, which happens right after a send, and dropped the words that arrived in that moment. A Stop froze a text that did not start at the beginning.
