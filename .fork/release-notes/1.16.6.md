# 🧠 Molfar Vertep 1.16.6

A small engine release about the **prompt cache**, with **Roleplay 4.127.0**. **Order:** get this engine release and restart, then press Update on **Roleplay** in Updates.

## ⏱️ How long a model's prompt cache lives (#112)
Settings > Connections and models > a model > **Cache lifetime**:
- **Provider's own** (as before): usually about 5 minutes after the last request. Until now this was the only behaviour, so every pause over 5 minutes paid the whole long prompt again.
- **Long**: asks the provider to keep the cache for an hour (Claude) or up to a day (GPT). No extra requests, but writing the cache costs more. It is offered only where it was seen to work: Anthropic itself, Claude through OpenRouter and OpenAI. Through a gateway such as NanoGPT, Claude ignores it and Argon refuses the request, so there it is greyed out and never sent.
- **Keep alive**: after a chat reply, a small request about every 5 minutes for up to 40 minutes, so a short cache does not lapse; nothing is written to the chat. Off by default; needs the model's prices; not for models on your own machine; stops by itself if the provider does not read the cache; not used with tools or with thinking on Claude. When it does not run, the panel says why.

Tried through NanoGPT with real requests: Gemini 3.8 Flash and Argon cache by themselves (they read part of the prompt; the cache lived 5 to 10 minutes, so keep-alive helps there); Claude Haiku through NanoGPT caches for 5 minutes only, so use Keep alive.

## 🎭 In Roleplay (4.127.0)
- **Request size popup:** how much of the last request came from the cache, what the model's cache setting is and, with Keep alive, how it is doing. "Show where the cache ends" marks the cut in the prompt peek.
- **Quest limits:** main quests up to 10, side up to 20, everyday up to 20 (new setting), steps per main quest without an upper limit (default 6).

## Known limits
- Checked with a mock model and with direct requests to a gateway; not through the engine against a real provider's usage, and the longer life of Gemini's cache with a cache key is one sample.
- The guide translations of the `models` page and of Roleplay's `long-chats` and `dashboard` pages were made by a fast model and checked only for structure.
- pi stays at 1.2.0: the newest releases (1.5.x) are less than a week old or were followed by a hotfix, and 1.4.0 changes the API; not tried.

## How to get it
From source: `git pull && bun install && (cd client-agent && bun install) && bun run build:client`, then restart. Downloads and the Android APK are on this release page. Apps: Updates > Roleplay > Update. See [CHANGELOG.md](https://github.com/MolfarWav/Molfar.Vertep/blob/main/CHANGELOG.md).
