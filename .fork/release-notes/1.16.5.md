# 🏠 Molfar Vertep 1.16.5

A small engine fix that goes with **Roleplay 4.124.0**: importing a big SillyTavern library as a zip works. **Order:** get this engine release and restart, then press Update on **Roleplay** in Updates.

## 📦 Import > Backup zip takes a big SillyTavern library
A zipped SillyTavern data folder reached 100% on the progress card and then showed an error. There were two causes, one in each part:
- **Roleplay 4.124.0:** the app bridge refuses a request body over 32 MB, and the whole zip (backgrounds and thumbnails included) went in one request ("Connection lost"). Now the pictures that are not cards are left out and the rest goes in parts of about 18 MB, in the order the importer needs (cards, then books, presets and personas, then chats).
- **Engine:** the archive was also copied into the sandbox call of every plugin of the app in turn, and a library of about 70 MB ran past 20 seconds in the first one, before the importer was asked. Only the plugin that reads zips gets it now.

## 🎭 Character sprites come with the library
The `characters/<Name>/joy.png` pictures of SillyTavern were listed as failed cards (28 errors for one character) and lost. They are now attached to the character of that name as expression pictures (Roleplay 4.124.0).

## 🛠️ Other changes
- **Engine:** a text file of a zip arrives as text up to 16 MB (it was 2 MB), so a chat transcript of 2 to 3 MB imports. A chat over about 3 MB is listed as not imported: the importer cannot write a chat file over 4 MB. Import that one with Chats.

## Known limits
- Checked with a 71 MB library and a made-up 53 MB one in a browser on a test engine; not with the reporter's own zip (its size and exact error were not seen).
- A sprite folder whose character is not in the same zip is left unattached, with a note.
- The guide translations of Roleplay's `settings` page (13 languages) were written without a native read.

## How to get it
From source: `git pull && bun install && (cd client-agent && bun install) && bun run build:client`, then restart. Downloads and the Android APK are on this release page. Apps: Updates > Roleplay > Update. See [CHANGELOG.md](https://github.com/MolfarWav/Molfar.Vertep/blob/main/CHANGELOG.md).
