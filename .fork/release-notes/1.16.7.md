# ⏱️ Molfar Vertep 1.16.7

A small engine fix: a **send in a long chat** no longer stops at 10 seconds in the Roleplay plugin. **Order:** get this engine release and restart. Roleplay needs no update.

## The error
"plugin roleplay__engine route POST /chats/<id>/send failed: The script execution has exceeded the maximum allowed time limit", on a phone or a busy computer, in a long chat. The plugin that builds the request has a time limit; since 1.16.3 the Roleplay plugin could ask for 30 s, but only for reads (opening the app), not for a send.

## What changed
- The limit the Roleplay plugin asks for (30 s) now applies to every route of the plugin, a send included. A plugin you import from outside keeps 10 s.

## Known limits
- The cause of the slowness is not found. A bench of the plugin's send on a 500-message chat took 25 to 27 ms on a computer in every Roleplay version from 4.115.0 to 4.128.0, so nothing got slower in the plugin's own code; the slowness was seen on a phone and on a computer under heavy load (see #422).
- Not tried on a phone.

## How to get it
From source: `git pull && bun install && (cd client-agent && bun install) && bun run build:client`, then restart. Downloads and the Android APK are on this release page. See [CHANGELOG.md](https://github.com/MolfarWav/Molfar.Vertep/blob/main/CHANGELOG.md).
