# 🔎 Molfar Vertep 1.16.8

A diagnostic release for one error. **Order:** get this engine release and restart. Roleplay needs no update for it (4.134.1 is the current Roleplay).

## The error
"plugin roleplay__engine route POST /chats/<id>/send failed: The script execution has exceeded the maximum allowed time limit". It still happened on a phone after 1.16.7, once on a new chat of under 50 messages with a small lorebook. In a chat like that the plugin's own work takes about a second, so the 30 s went somewhere else.

## What changed
- **The error now says where the time went.** The red toast ends with a note in brackets: how long the call ran, how much CPU the engine got, how long the script stood still, and the likely cause. The cause is one of three:
  - **The device gave the engine little CPU.** A phone pauses the engine app while you are in the browser, or a computer is busy with something else.
  - **Other plugin calls shared its worker.**
  - **The plugin's own work took that long.**

  If you see this error, send a screenshot of the whole toast: the note answers what we could not see before.
- **Slow calls are written to the server log.** Any plugin call that takes 5 s or more gets a line, as does any call that runs out of time. The line has the same numbers plus the wait for the app's data folder and for a free worker.

Limits and scheduling are unchanged; this release only measures.

## A correction to 1.16.7
The 1.16.7 notes said the plugin's send had not got slower ("25 ms on a computer"). That bench never reached the pass that builds the prompt. Measured in the engine's sandbox, that pass took 6.8 s on a long chat whose lorebook scans the last 100 messages. Roleplay 4.134.1 brought it down to 4.3 s.

## If the engine runs on your phone (Termux and the like)
Android may slow down or pause an app that is not on screen. Turn off battery optimisation for the app that runs the engine, and keep its wake lock on (`termux-wake-lock` in Termux). The note in the error will show whether this was the cause.

## How to get it
From source: `git pull && bun install && (cd client-agent && bun install) && bun run build:client`, then restart. Downloads and the Android APK are on this release page. See [CHANGELOG.md](https://github.com/MolfarWav/Molfar.Vertep/blob/main/CHANGELOG.md).
