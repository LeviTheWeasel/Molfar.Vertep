# 🧠 Molfar Vertep 1.18.1

A small engine release: the embedding model field in Settings > Memory no longer loses what you type, and it offers a list to search. **Order:** get this engine release and restart. Roleplay 4.139.1 (sprite windows on a phone) comes as an app update and does not need it.

## 🧠 The embedding model field saves what you type
In Settings > Memory, the **Embedding model** field used to save only through the small Save button. A name typed on a phone and left with Enter, or with a tap elsewhere, was gone the next time you opened the page, and the default was back. Saving an OpenRouter key, changing the provider or connecting a model on this computer also wiped a name you had typed but not saved.
- The model now saves when you press Enter, leave the field, or pick a name from the list. Until then the field says "Not saved yet", and other actions on the page leave your text alone.
- **A list to search.** For OpenRouter the field offers its embedding models (38 today, with their prices per million tokens). For your own API connections it offers the models their server lists. Start typing to narrow it down, or type any name by hand. Automatic has no list.
- **The default is named for both paths.** With Automatic and no model chosen, API connections get `text-embedding-3-small` and OpenRouter gets `qwen/qwen3-embedding-4b`. The line under the field used to name only the first, even for a phone that only has OpenRouter. One chosen name is sent to every source Automatic tries.
- Saving the choice now leaves a line in the engine log, so a choice that seems to come back to the default can be traced.

## 📦 What arrives through app updates
- **Roleplay 4.139.1:** sprite windows work on a phone. The window and the round pictures of the others stand above the message box and step aside while you type, an unfolded window always lands on screen, a swipe over a sprite scrolls the chat, and a window set to one character reads that character's emotion from the sentences that name them. Press Update in the Updates dialog to get it.

## Other changes
- A device's embeddings choice is still never synced (since 1.16.10). A phone running an engine older than that keeps the choice in the synced settings, and a pull from another device can bring it back to Automatic: update that engine too.
- Guide page Settings is updated in all 14 languages (translations by a model, no native read).

## How to get it
From source: `git pull && bun install && (cd client-agent && bun install) && bun run build:client`, then restart. Downloads and the Android APK are on this release page. See [CHANGELOG.md](https://github.com/MolfarWav/Molfar.Vertep/blob/main/CHANGELOG.md).
