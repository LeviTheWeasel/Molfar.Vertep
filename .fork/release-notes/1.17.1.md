# 🛠️ Molfar Vertep 1.17.1

A small fix release for the Windows program. **Order:** get this engine release and restart. Roleplay 4.138.1 comes as an app update (Updates dialog, press Update) and fixes typing lag and a regex import problem; it does not need this engine release.

## 🪟 The Windows program no longer closes without a word
A user reported that `molfar-vertep.exe` showed its first line and closed at once. One cause we could reproduce: after a power cut or a forced shutdown the accounts file (`users.json`) could be left empty or cut off, because it was rewritten in place. The program then stopped and the console window vanished with it, so nothing could be read.
- **The accounts file is saved safely.** `users.json` and `sessions.json` are written to a temporary file and renamed over the old one, so a crash in the middle leaves the old list, not an empty file.
- **A damaged file is explained.** If `users.json` still cannot be read, the program stops with a message that names the file, says that the accounts' own data in the `users` folder is untouched, and what to do: close the program, rename the file (for example to `users.json.damaged`), start again and create the account again. Nothing is reset silently.
- **The window stays open.** Every fatal exit of the downloaded Windows program now prints the reason in one line with the path of the log file, and waits for Enter. The long technical text goes to the log file only.

This fixes the case we could reproduce. Whether it was the reporter's cause is not confirmed; if the program still closes, the line it now prints says why.

## 🛠️ Fixes
- **Apps' storage writes are cheaper.** An app frame keeps a copy of the app's storage in its own address so a reload keeps what was typed; it was encoded one character at a time, about 120 ms of every write with 1.2 MB stored. It is now about 20 ms. The larger part of the typing-lag fix is in Roleplay 4.138.1.

## How to get it
From source: `git pull && bun install && (cd client-agent && bun install) && bun run build:client`, then restart. Downloads and the Android APK are on this release page. See [CHANGELOG.md](https://github.com/MolfarWav/Molfar.Vertep/blob/main/CHANGELOG.md).
